# Never Crisis — FFVII EVER CRISIS のセルフホスト型ゲームサーバー。公式サービス終了後もミッドガルを遊び続けよう。

- **目的：** 公式サービスの終了後も、特にストーリーを中心としたシングルプレイを、自分のPCで引き続き遊べるようにします。
- **導入方法：** まずゲームをインストールし、このパッケージをゲームフォルダに解凍します（既存のファイル2つを置き換え、残りのファイルを追加します）。その後、`FF7ECServer.exe` を実行してください。ゲームが起動し、終了時には必要な設定が自動的にクリーンアップされます。
- **管理者権限：** 起動時に一度だけ、Windows の hosts ファイルに数行追加するための管理者権限が必要です。これにより、ゲームの接続先がこのサーバーに切り替わります。追加した設定は終了時に削除されます。
- **動作要件：** Windows 10/11（64bit）、完全なゲームフォルダ（`FF7EC_Data`、`octo` および必要なファイル一式）、ポート443が使用可能であること。Steam クライアントもインターネット接続も、追加のインストールも不要です。
- **意図的に含めていないもの：** ゲーム本体はスクウェア・エニックスの所有物であるため、各自のインストール環境から用意してください。また、サーバーのソースコードも含まれていません。

## フォルダ構成

ゲームフォルダ内には、以下の3種類のファイルが配置されます。

**1. ゲーム本体 — 自分で用意するもの（約47 GB）：**

| ファイル／フォルダ | 説明 |
|---|---|
| `FF7EC.exe`（650 KB）、`GameAssembly.dll`（140 MB）、`baselib.dll`（400 KB）、`UnityCrashHandler64.exe`、`Applibot.GraphicsUtility.dll`、`NativeVideoUtility.dll` | ゲーム本体のファイル |
| `FF7EC_Data\`（387 MB） | `il2cpp_data`、`Resources`、`StreamingAssets`、`Plugins`、`data.unity3d` など |
| `octo\`（46.5 GB、235,000ファイル） | 公式サービス稼働中にゲームがダウンロードした、すべてのモデル、ステージ、エフェクト、ムービー。これがないと戦闘を読み込めません。 |

**2. このパッケージ — 解凍してゲームフォルダに上書きするもの（48 MB）：**

| ファイル／フォルダ | 説明 |
|---|---|
| `FF7ECServer.exe`（4 MB） | サーバー本体。これを実行してゲームをプレイします。 |
| `FF7ECServer.pak`（23 MB） | サーバーのデータ |
| `items.txt`、`README.md` | `--give` オプションで使用する全アイテムID一覧と、このREADME |
| `UnityPlayer.dll`（29 MB）、`FF7EC_Data\Plugins\x86_64\steam_api64.dll` | 置き換えられるゲームファイル2つ |
| `save\MasterData\`（11 MB）、`save\LocalizeText\`（1 MB） | 公式サービスが最後に公開した時点のゲームテーブルとテキスト |

**3. 初回起動時にサーバーが作成するもの：**

| ファイル／フォルダ | 説明 |
|---|---|
| `config.ini`、`events.ini` | 設定ファイル（詳細は後述） |
| `ff7ec_account_id.txt` | オフラインアカウントの番号 |
| `data\` | アカウントデータ、プレゼントボックス、サーバー証明書 |
| `save\GameSave\`、`save\MessagePack\` | ゲーム本体のセーブデータとキャッシュ |
| `backups\` | アカウントをリセットする前のバックアップ |

**進行状況を維持するには、`data\`、`save\GameSave\`、`ff7ec_account_id.txt` の3つをまとめてバックアップしてください。** それ以外のファイルは、必要に応じて置き換えられます。

## 動作する機能

ストーリーチャプター、サイドストーリー、キャラクターストーリー、ダンジョン、エリア、塔、デイリークエスト、イベント（ソロ、クラッシュバトル、クライシスバトルを含む）、ガチャ、ショップ、クラフト、チョコボ、ハイウインド、ミッション、ログインボーナス、シーズンパスに対応しています。

ギルドも自分専用のものを作成でき、デイリーミッション、ボーナス、ログインボーナス、実績が機能します。ギルドチャットも自分だけで利用できます。

終了済みのソロイベントは `events.ini` から再開できます。この記事の作成時点で開催中だったガチャ（2026年10月7日までの開催期間が設定されていたもの）は、期限を過ぎても引き続き利用できます。すでに終了していたガチャは、公式サービス側で提供割合のデータが削除されているため、復活できません。

## 動作しない機能

- **協力プレイ（プライベートルーム、マッチング）：** 戦闘処理を担っていたサーバーがすでに存在しないため利用できません。協力プレイ用ミッションは、ソロ戦闘でも達成できます。
- **ギルドバトル、他のギルドへの加入、フレンド、ランキング、リアルマネーによる購入、アカウント引き継ぎ：** 他のプレイヤー、または公式サービスが必要なため利用できません。
- **ダメージチャレンジ：** 協力プレイと同じ戦闘サーバーを必要とするため利用できません。
- **ピックアップガチャとコラボガチャのタブ：** 提供割合のデータが失われているため、これらのタブは空になっています。

## 公式サービスとの主な違い

- ガチャの提供割合にはゲーム本来のテーブルデータを使用しています。戦闘報酬のドロップ率は、記録されたプレイデータから推定しています。確定ではないドロップの発生率や、クリア時に武器・マテリアが追加される確率は、もともとゲームデータに含まれていませんでした。
- ストーリー中に加入するキャラクターは、最もレベルの低いキャラクターと同じレベルで加入します（公式の仕様は不明です）。
- 一部のミッション連鎖やレアカウンターは、公式サービスと進行状況がわずかに異なる場合があります。
- クラッシュバトルとクライシスバトルのスコアは記録されますが、ランキングは他のプレイヤーとの競争だったため再現できません。
- 成長ボードのチュートリアルでは、最初のボードを開いた後に画面がフリーズすることがあります。これはオンライン版にも存在していたゲーム自体の不具合です。ゲームを再起動してください。

## 設定

サーバーと同じフォルダにある `config.ini` を編集・保存し、サーバーを再起動してください。

| 設定項目 | 説明 |
|---|---|
| `reopen_events` / `events.ini` | 終了済みのソロイベントをすべて、または個別に再開します。 |
| `keep_expired_items` | 期限切れのイベント通貨を引き続き使用できるようにします。 |
| `infinite_crystals`、`infinite_paid_crystals`、`infinite_stamina`、`infinite_gil` | 対象のクリスタル、スタミナ、ギルを消費しなくなります。 |
| `unlock_season_pass`、`season_pass` | 有料パスの報酬トラックを開放し、対象シーズンを選択します（`0` = 最新シーズン）。 |
| `solo_counts_as_coop` | ソロ戦闘を協力プレイ用ミッションの達成対象にします（デフォルトで有効）。 |

## コマンドラインオプション

ゲームフォルダ内でコマンドプロンプトを開きます（エクスプローラーのアドレスバーに `cmd` と入力）。オプションを指定してサーバーを起動すると、通常どおりサーバーとゲームが起動します。

| コマンド | 説明 |
|---|---|
| `FF7ECServer.exe --give NAME=COUNT` | 通貨やアイテムをアカウントに追加します。アイテムごとに指定でき、数量も自由に設定できます。 |
| `FF7ECServer.exe --reopen-events` | `events.ini` の設定を無視して、終了済みのソロイベントをすべて再開します。 |
| `FF7ECServer.exe --reset-account`、`--restore-account FOLDER` | 「最初からやり直す」を参照してください。 |

**`--give` で指定できる名前：**

`crystals`、`red_crystals`（有償クリスタル）、`gil`、`stamina`、`chocobo_medals`、`weapon_medals`、`crisis_medals`、`dungeon_keys`、`gear_vouchers`、`memory_vouchers`、`parts`

これら以外のアイテムは、`item=ID=COUNT` の形式で指定してください。IDはサーバーと同じフォルダにある `items.txt` で確認できます。このファイルには全アイテムのID、種類、名称が記載されています。ガチャチケットはバナーごとに別々のIDが割り当てられています。

```text
FF7ECServer.exe --give crystals=3000 --give gil=200000
FF7ECServer.exe --give item=9003=100 --give item=10012=30
```

指定した数量はゲーム起動前にアカウントへ追加され、次回ログイン時に反映されます。代わりに `config.ini` の `infinite_*` 設定を使えば、対象のリソースを消費しないようにすることもできます。

## 最初からやり直す

- **タイトル画面の「Reset Game Data」：** 新しいアカウントを作成し、チュートリアルを最初から開始します。ダウンロード済みのゲームデータは保持されます。
- **`FF7ECServer.exe --reset-account`：** ゲームが起動しない場合などに、ゲーム外から同じリセットを実行できます。以前のアカウントとセーブデータは `backups\<stamp>-reset` に保存されます。
- **`FF7ECServer.exe --restore-account backups\<folder>`：** バックアップしたアカウントとセーブデータを復元します。復元によって置き換えられる現在のデータも、事前にバックアップされます。
